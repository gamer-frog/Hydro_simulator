## HydroHarvest NFT

Aplicación 3D recuperada desde el repositorio PLAYGROUND. Simulá un emprendimiento hidropónico, diseñá módulos NFT y compará otros sistemas, cultivos, costos y cosechas. Pensada para escritorio y pantallas táctiles.

### Ejecutar localmente

Necesitás Python 3 (o cualquier servidor estático). Desde la raíz:

```sh
python3 -m http.server 8000
```

Abrí <http://localhost:8000>. La partida se guarda localmente en el navegador; no se requiere instalación de dependencias ni conexión a un backend.

La aplicación recuperada está en `index.html`, `css/`, `js/` y `vendor/`. El rescate y la procedencia se documentan en [`docs/RESCUE_PLAYGROUND.md`](docs/RESCUE_PLAYGROUND.md); la versión anterior y los historiales están preservados en `archive/` y `docs/history/`.
